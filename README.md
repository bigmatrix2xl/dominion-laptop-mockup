# Ноутбук для кейса

[Открыть инструмент](https://bigmatrix2xl.github.io/dominion-laptop-mockup/)

Выберите один из 20 макетов, загрузите скриншот или вставьте его из буфера и скачайте прозрачный PNG. Комбинации клавиш и рекомендуемые размеры указаны на странице.

`index.html` содержит весь инструмент. Его можно открыть локально или разместить на статическом хостинге. Обработка изображения выполняется в браузере, без отправки снимков на сервер.

Условия распространения шрифта Montserrat приведены в [OFL-Montserrat.txt](OFL-Montserrat.txt).
